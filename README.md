# KMTC Search Portal

The KMTC Search Portal is a web application designed for the Kenyan Medical Training College (KMTC) students and staff. The portal allows users to search for courses, view subject details, and check academic progress, all through a modern, responsive interface.

## Features

- **Search Courses**: Students and staff can search for various courses offered at KMTC.
- **Subject Information**: View detailed information about specific subjects and their grades.
- **User Authentication**: Secure login system for students and staff.
- **Responsive Design**: The portal is fully responsive and can be accessed on any device.
- **Database Integration**: A robust database setup for managing courses, subjects, and grades.

## Installation

To run this project locally, follow these steps:

1. **Clone the Repository:**

   ```bash
   git clone https://github.com/Muindi6602/kmtc_search_portal.git
   ```

2. **Navigate to the Project Directory:**

   ```bash
   cd kmtc_search_portal
   ```

3. **Set Up Your Local Development Environment:**

   - Make sure you have **XAMPP** or any local server set up to run PHP and MySQL.
   - Import the provided **kmtc.sql** file into your database.

4. **Configure Your Database Connection:**

   Open the `config.php` file and update the database connection settings with your local database credentials.

5. **Start the Server:**

   - Ensure your local server (XAMPP) is running.
   - Access the project via `localhost` in your browser.

## Usage

Once the application is set up:

- **Login** with your student or staff credentials.
- **Search Courses** by entering the course name or subject.
- View detailed **Subject Information** and grades.
- Manage **user authentication** securely using the integrated login system.

## Technologies Used

- **PHP**: Backend programming language.
